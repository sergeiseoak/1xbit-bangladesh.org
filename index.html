Provably Fair Games at 1xBit

Some games on 1xBit use provably fair technology. This is particularly relevant to crash, dice and other crypto-native formats.

A provably fair system allows a game result to be checked using cryptographic information associated with the round. It doesn't predict future results or improve the player's chances of winning.

The feature should be checked within the individual game. A live roulette table or conventional video slot shouldn't automatically be assumed to use the same verification system as a crypto-native dice game.
